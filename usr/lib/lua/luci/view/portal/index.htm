Tentang Portal Manager

Apa fungsi sistem ini?

Portal Manager membantu router OpenWrt Anda untuk login otomatis ke halaman login WiFi publik (seperti @wifi.id, WMS, atau hotspot lainnya). Setelah Anda mengatur sekali, sistem akan menangani login ulang secara otomatis di latar belakang setiap kali koneksi terputus, tanpa perlu membuka browser atau mengetik password lagi.

Bagaimana cara memakainya dari awal?

  1. CEK INTERFACE: Tekan tombol ini untuk memindai semua jaringan yang terhubung ke router. Sistem akan mendeteksi apakah ada halaman login (captive portal) di jaringan tersebut, lalu menampilkan hasilnya dalam bentuk tabel: tipe portal, nama interface, IP, MAC address, dan URL portal.
  2. PILIH INTERFACE: Klik tombol ini pada baris jaringan yang ingin Anda atur. Semua data hasil pemindaian (URL, MAC, parameter portal) akan otomatis terisi ke form di bawahnya.
  3. Lengkapi Data di Form: Isi username, password, dan sesuaikan pengaturan lain jika perlu (penjelasan detail ada di bagian bawah).
  4. LOGIN: Tekan tombol ini untuk mencoba login sekarang juga. Ini berguna untuk memastikan username dan password Anda benar sebelum disimpan. Jika berhasil, tombol akan berubah menjadi LOGOUT.
  5. SIMPAN: Setelah login berhasil, tekan tombol ini untuk menyimpan seluruh pengaturan ke router. Jika Anda mengaktifkan fitur Auto Login/Reconnect, sistem akan otomatis menjaga koneksi Anda tetap aktif, bahkan setelah router dimatikan dan dinyalakan kembali.

Apa saja yang bisa diatur di form?

  • MAC Address: Anda bisa memakai MAC bawaan perangkat, atau menggantinya agar router terlihat sebagai perangkat lain. Pilih tipe perangkat (Android, Windows, Mac, Linux) untuk mendapatkan MAC dari vendor asli, atau tekan RANDOM untuk menghasilkan MAC acak. Tombol APPLY MAC akan menyimpan perubahan ke konfigurasi wireless router.
  • URL Portal: Biasanya sudah terisi otomatis dari hasil pemindaian. Jika perlu diubah, Anda bisa mengeditnya langsung. Setiap kali URL berubah (baik karena diedit manual, ditekan Enter, atau diklik DETECT URL), sistem akan otomatis mengenali tipe portal berdasarkan path-nya (misalnya /login/, /loginjs/, /loginocs/, atau /wms/) dan menyesuaikan parameter yang diperlukan.
  • Parameter Portal: Field seperti GW ID, Client MAC, WLAN, Session ID, dan IPC biasanya tidak perlu diisi manual karena diambil langsung dari URL portal. Field ini hanya muncul jika tipe portal memang memerlukannya.
  • Login Method: Pilihan metode login (Standar, Komunitas, ISP, Wico) yang menentukan bagaimana username Anda akan diformat sebelum dikirim ke server. Opsi ini hanya aktif untuk tipe portal yang mendukung.
  • Username & Password: Kredensial yang akan dikirim ke server portal saat login.

Apa fungsi tombol-tombol di tabel Profil Tersimpan?

  • EDIT: Membuka profil yang sudah tersimpan ke dalam form. Anda bisa mengubah username, password, atau pengaturan lain. Setelah diubah, tombol SIMPAN akan berubah menjadi UPDATE.
  • UPDATE: Menyimpan perubahan ke profil yang sudah ada. Data lama akan ditimpa dengan data baru.
  • HAPUS: Menghapus profil secara permanen dari router. Sistem akan berhenti menjaga koneksi untuk profil tersebut.

Apa itu LOGOUT?

Tombol ini hanya muncul setelah Anda berhasil login. Fungsinya untuk memutus sesi aktif di server portal. Gunakan ini jika Anda ingin berhenti menggunakan jaringan tersebut tanpa menghapus profil.

Penjelasan Fitur Lanjutan (Advanced Settings)

  • Auto Login/Reconnect: Mengaktifkan sistem penjaga koneksi. Anda bisa mengatur: Interval Cek (berapa detik sistem mengecek koneksi, rentang 30-300 detik), Interval Reconnect (jeda antar percobaan login ulang), dan Maksimal Percobaan (batas retry sebelum sistem berhenti dan menunggu perhatian Anda).
  • Anti Blocking: Memberikan jeda waktu sebelum mencoba login ulang. Tujuannya agar server portal tidak mencurigai router Anda melakukan request terlalu agresif.
  • Random Hostname: Mengganti nama router secara berkala (setiap 1 hari, 7 hari, 30 hari, atau 1 tahun). Ini membuat router terlihat sebagai perangkat baru di mata server portal, berguna untuk menghindari pembatasan kecepatan berbasis identitas perangkat.
  • Kirim Notifikasi: Mengirim pesan ke Telegram Anda saat terjadi peristiwa penting: login berhasil, login gagal berulang, atau maksimal percobaan tercapai. Anda perlu mengisi Bot Token dan Chat ID Telegram.

Keamanan & Privasi

Seluruh data (username, password, token, parameter portal) disimpan lokal di router Anda. Tidak ada data yang dikirim ke server pihak ketiga, kecuali notifikasi yang secara sadar Anda aktifkan ke akun Telegram Anda sendiri.

Versi Sistem: 2.0.0
Lingkungan: OpenWrt 21.02+ dengan LuCI
